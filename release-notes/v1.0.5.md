Spot the Scam v1.0.5 fixes two layout problems on narrow phones. Like earlier versions, it works offline and is free, with no ads, analytics, trackers, account, cloud upload, or in-app purchases. The App ID (com.wgra.spotthescam) is unchanged, and the app has no INTERNET permission.

## Install
- **Have v1.0.4?** Install v1.0.5 straight over it. It's signed with the same key.
- **Have v1.0.3 or older?** Uninstall it first. Since v1.0.4 the app uses a new release key, so Android won't install it over v1.0.3 or older.

Download `SpotTheScam-v1.0.5.apk`, allow installs from unknown sources, and install it. You don't need an account or a network connection.

## Changes
- **Game screen title:** on 360dp-wide phones (most Android phones), the title cut off as "Question 1 …". It now reads "Question 1/10".
- **Results buttons:** "Change Level" wrapped onto two lines. The bottom buttons now share the width evenly and stay on one line.
- **Screenshots:** the README screenshots now show the current app.
- Version 1.0.4 → 1.0.5 (versionCode 104 → 105).

No changes to the scenario bank, levels, license (GPL-3.0-only), or privacy setup.
