Spot the Scam v1.0.4 brings the new v2 game and a new app design. Like earlier versions, it works offline and is free, with no ads, analytics, trackers, account, cloud upload, or in-app purchases. The App ID (com.wgra.spotthescam) is unchanged, and the app has no INTERNET permission.

## ⚠️ Uninstall the old version first
This release is signed with a **new WGRALGO release key**. Android will not install it over v1.0.0–v1.0.3. If you have an older version installed, **uninstall it first**, then install this one. The app doesn't store any accounts or personal data, so uninstalling loses nothing. Future updates will install over v1.0.4 normally.

## What's new
- **New 100-scenario bank (v2):** real-life texts, emails, calls, letters, apps, websites, social media, and in-person situations. There are 20 scenarios per difficulty level: 10 safe and 10 risky at every level.
- **Choose your level:** All Levels (2 from each level, easy to hard), Beginner (levels 1–2), Intermediate (level 3), or Expert (levels 4–5).
- **Balanced rounds:** each round has 10 questions with 4–6 safe answers, ordered from easier to harder.
- **Better feedback:** every answer shows **Why** (the clue) and **What to do** (the real-life action).
- **New app design:**
  - top app bar with a back button and a live score
  - a progress bar
  - message-style scenario cards that show the sender
  - fixed bottom buttons sized for thumbs
  - a results screen with a score ring and expandable answer review
  - About, Privacy, and Credits in slide-up sheets
- Version 1.0.3 → 1.0.4 (versionCode 103 → 104).
